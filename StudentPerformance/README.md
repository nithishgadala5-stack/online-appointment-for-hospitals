\# 🎓 Student Performance Prediction



\## 📌 Project Description



This is a beginner-friendly Machine Learning project that predicts a student's final exam score based on:



\* Study hours

\* Attendance

\* Previous exam score

\* Assignments completed

\* Sleep hours



The project uses \*\*Linear Regression\*\* to make predictions.



\## 🛠️ Technologies Used



\* Python

\* Pandas

\* NumPy

\* Matplotlib

\* Scikit-learn

\* Streamlit



\## 🤖 Machine Learning Model



The project uses:



\*\*Linear Regression\*\*



The dataset is divided into training and testing data. The model learns from the training data and predicts final scores for new students.



\## 📊 Model Evaluation



The project uses:



\* Mean Absolute Error (MAE)

\* R² Score



\## 🚀 How to Run



\### 1. Install the required libraries



```bash

pip install pandas numpy matplotlib scikit-learn streamlit

```



\### 2. Run the Streamlit application



```bash

streamlit run app.py

```



\### 3. Enter student information



Enter:



\* Study hours

\* Attendance

\* Previous score

\* Assignments completed

\* Sleep hours



Then click:



\*\*Predict Final Score\*\*
